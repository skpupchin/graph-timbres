Stopped. Start with the Spark’s MUSIC VOLUME low.

Input gain boosts the signal before the graph and its saturation vertices. Start at +24 dB and raise it for more drive; lower Output volume to control listening level. Internal graph input may exceed 0 dBFS without being clipped. Gain and mix changes are live; Apply graph is not needed for them. Bypass sends the captured input directly to the output volume control. Mute app output silences this page; guitar still audible with mute on comes from another path, such as the Spark’s direct monitoring. A ceiling at ±0.98 limits output peaks; lower gain if the output meter shows LIMIT. Wet loudness is not normalized.

Build the graph

Graph ready.

Select a vertex to edit its R/N type, resonator frequency/damping or saturation drive, and set IN/OUT. Select an edge to edit its delay multiplier. Graph and network edits take effect when you press Apply graph, with a 20 ms crossfade. Feedback also controls signal transfer between vertices: 0% silences a wet output on another vertex. Vertex positions do not change the sound.
