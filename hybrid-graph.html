Как это работает

R — локальный затухающий осциллятор, N — линейное звено или насыщение tanh. Соседи обмениваются сигналами по двум независимым линиям задержки; это не модель масс, соединённых пружинами. Вход каждого узла — среднее пришедших сигналов с глобальной обратной связью и внешнее возбуждение. Фильтр действует на сигналы соседей. Для R используется точное решение за шаг при постоянной силе; его выход — скорость, нормированная так, чтобы резонансное усиление было равно единице. Ограниченная обратная связь, усреднение соседей и затухание предотвращают разгон сети. Для шумового импульса и аудиофайла обработанный сигнал нормируется по пику до 0,8 перед Dry/Wet и регулятором громкости. Используется один коэффициент для всей записи, поэтому динамика сигнала сохраняется. После микширования пиковое усиление уменьшается только при превышении 0,98. Насыщение может создавать алиасинг на высоких частотах.
