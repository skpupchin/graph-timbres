Нелинейные тембры графов

Пружины F(d) = k(d + αd³/d₀²)

Граф

Клик по пустому месту — новая вершина. Два клика по вершинам — соединить или убрать ребро. ПКМ по вершине — удалить. Максимум 12 вершин.

Параметры

α = 0 возвращает линейную модель. После изменения параметров нажми «Рассчитать и слушать» заново. Громкость wet нормируется относительно исходника, поэтому 100% wet действительно означает полный переход на обработанный звук.

Источник звука

Обрабатывается весь аудиофайл (22 050 Гц, моно). Всё локально, без загрузки на сервер. Для длинных записей потребуется больше памяти.

Готово. Выбери входную и выходную вершины.

Результат

Временной сигнал после моделирования

Спектр выходного звука · фрагмент записи

Новый спектр рассчитывается через FFT; при α = 0 система линейна и новых частот не создаёт. При α > 0 появляются гармоники и интермодуляция.

Математическая модель

Для вершины i (масса = 1):

q̈ᵢ + (2/τ)q̇ᵢ + ω₀² [ εqᵢ + Σⱼ kᵢⱼ(dᵢⱼ + αdᵢⱼ³/d₀²) ] = bᵢu(t)

dᵢⱼ = qᵢ − qⱼ, ω₀ = 2πa, ε = 0.01, d₀ = 0.005. Слабое закрепление ε убирает нулевую трансляционную моду. α > 0 даёт жёсткую (hardening) пружину. Выход — смещение выбранной вершины. На удар задаётся начальная скорость; трек подаётся как внешняя сила. Для слышимого действия на обычной записи кубический член масштабирован характерным смещением d₀ = 0.005: F(d) = k[d + αd³/d₀²].

Расчёт — прямое интегрирование уравнений полунеявным методом Эйлера с подшагами и затуханием; на каждом подшаге вычисляются нелинейные силы на рёбрах. Это не свёртка с импульсным откликом. Для очень больших α и амплитуд результат может перестать быть устойчивым — в таком случае будет показана ошибка. При обработке трека dry/wet смешиваются после интегрирования.

Что проверить

Поставь α = 0, затем α = 5–10 и сравни звуки. Для демонстрации новых частот лучше загружать запись чистых гитарных нот или двух синусоид: изменения будут отчётливее, чем на насыщенном миксе. Попробуй поменять входную и выходную вершины. Увеличение «Силы входного сигнала» усиливает нелинейность даже при неизменном α. Wet автоматически выравнивается по среднеквадратичной громкости с оригиналом, а ползунок «Громкость wet после выравнивания» задаёт дополнительное усиление.
