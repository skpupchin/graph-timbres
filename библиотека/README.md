# Библиотека: графы с заданными колебательными частотами

Небольшая подборка для проекта «Тембры графов». Ссылки и PDF проверены 5 октября 2026 года. Это ориентир по нескольким направлениям, а не исчерпывающий обзор литературы.

## Как это связано с прототипом

В прототипе используется комбинаторный лапласиан L = D − A. Массы вершин и жёсткости рёбер равны 1, частоты задаются формулой fₖ = a√λₖ. Поэтому искомые отношения собственных значений — квадраты отношений частот.

Важно различать задачи:

- **Без весов:** подобрать сам набор связей. Произвольный спектр не обязательно реализуем.
- **С весами:** подобрать положительные жёсткости пружин. Если разрешён полный граф, любой набор положительных собственных значений с одним дополнительным нулём можно реализовать точно.
- **Восстановление:** найти граф по спектру существующей конструкции. Решение не обязательно единственно.
- **Заданный тембр при ударе:** собственных значений недостаточно, поскольку амплитуды зависят также от собственных векторов и пары «удар / прослушивание».

## 1. Однозначность восстановления

**Edwin R. van Dam, Willem H. Haemers. Which graphs are determined by their spectrum? (2003).** Linear Algebra and its Applications, 373, 241–272.

Классический обзор: когда спектр определяет граф однозначно, а когда разные неизоморфные графы имеют одинаковый спектр. Рассматриваются разные матрицы графа, включая лапласиан. Это теоретическая основа для понимания неоднозначности обратной задачи, а не универсальный алгоритм построения графа.

**Для проекта:** несколько конструкций могут одинаково звучать в режиме «Весь спектр», но давать разные локальные отклики на удар.

- [Локальный PDF](01-van-Dam-Haemers-2003.pdf)
- [Открытая копия в репозитории университета](https://pure.uvt.nl/ws/files/518670/Whichgra.pdf)
- [DOI](https://doi.org/10.1016/S0024-3795(03)00483-X)

## 2. Поиск через колебательный спектр

**Mads Ipsen, Alexander S. Mikhailov. Evolutionary reconstruction of networks (2002).** Physical Review E, 66, 046109. Препринт опубликован в 2001 году.

Очень близкая к нашему эксперименту работа. Граф моделируется как система колебаний с частотами √λₖ. Из частот строят сглаженную спектральную плотность, затем изменениями связей и алгоритмом Метрополиса уменьшают различие с целевой плотностью. Авторы демонстрируют точные реконструкции небольших сетей и приближения для более крупных примеров; универсальной гарантии восстановления это не даёт.

**Для проекта:** полезный образец функции ошибки и поиска без весов. Музыкальную цель можно оценивать в центах, сохранив общую схему поиска.

- [Локальный PDF препринта](02-Ipsen-Mikhailov-2002.pdf)
- [arXiv](https://arxiv.org/abs/nlin/0111023)
- [Издательская версия в открытом доступе](https://harvest.aps.org/v2/journals/articles/10.1103/PhysRevE.66.046109/fulltext)
- [DOI](https://doi.org/10.1103/PhysRevE.66.046109)

## 3. Генерация спектрально похожих графов

**Alana Shine, David Kempe. Generative Graph Models based on Laplacian Spectra (2019).** The World Wide Web Conference, 1691–1701.

Предлагаются методы генерации случайных графов, чей лапласианный спектр приближает спектр исходного графа. Цель — получить спектрально похожие конструкции, а не обязательно восстановить оригинал. Работа исследует также другие свойства полученных сетей.

**Для проекта:** полезна постановка «выдать несколько графов с похожим звуком». Цель в статье берётся из существующего графа, поэтому результаты не гарантируют реализацию произвольного аккорда.

- [Локальный PDF](03-Shine-Kempe-2019.pdf)
- [Открытая копия](https://network-games-muri.engin.umich.edu/wp-content/uploads/sites/439/2019/04/generative-wwwcommittee-2019.pdf)
- [Код авторов](https://github.com/alanadakotashine/spectral_generation)
- [DOI](https://doi.org/10.1145/3308558.3313631)

## 4. Прямое построение взвешенного графа

**Karel Devriendt, Renaud Lambiotte, Piet Van Mieghem. Constructing Laplacian matrices with Soules vectors: inverse eigenvalue problem and applications (2019, препринт).**

Раздел 7 описывает построение лапласианов с заданным положительным спектром, дополняемым нулевым значением. Используются специальные ортонормированные векторы — векторы Soules, организованные бинарным деревом. Получаются взвешенные графы. Дерево задаёт структуру построения; итоговый граф не обязательно является деревом.

**Для проекта:** альтернатива перебору: задать частоты, возвести их в квадрат, построить матрицу и получить веса рёбер из её отрицательных внедиагональных элементов. Не решает задачу единичных весов.

- [Локальный PDF](04-Devriendt-et-al-2019.pdf)
- [arXiv](https://arxiv.org/abs/1909.11282)

## 5. Какие спектры допускает фиксированная топология?

**Shaun Fallat, Himanshu Gupta, Jephian C.-H. Lin. Inverse eigenvalue problem for Laplacian matrices of a graph (2024, препринт, версия v2).**

Изучаются реализуемые спектры взвешенных лапласианов при фиксированном наборе рёбер: полные графы, звёзды и небольшие конструкции, включая ограничения на кратности собственных значений.

Особенно важна **теорема 2.5**: любой набор 0, λ₂, …, λₙ с положительными λ₂, …, λₙ реализуется положительными весами рёбер полного графа Kₙ. Доказательство даёт рекурсивную конструкцию.

**Для проекта:** три заданные частоты можно точно получить на четырёх вершинах с шестью взвешенными рёбрами. Например, для равномерно темперированного минорного трезвучия нужны собственные значения, пропорциональные 1, 2^(1/2), 2^(7/6), плюс ноль. Массы могут оставаться единичными.

- [Локальный PDF](05-Fallat-Gupta-Lin-2024.pdf)
- [arXiv](https://arxiv.org/abs/2411.00292)
- [HTML, включая теорему 2.5](https://arxiv.org/html/2411.00292v2)

## 6. Настройка спектральных ограничений через веса

**S. Yusef Shafi, Murat Arcak, Laurent El Ghaoui. Graph Weight Allocation to Meet Laplacian Spectral Constraints (2012).** IEEE Transactions on Automatic Control, 57(7), 1872–1877.

Выбор весов вершин и рёбер для выполнения верхних и нижних ограничений на собственные значения. Используются выпуклая оптимизация, линейные матричные неравенства и полуопределённое программирование.

**Для проекта:** полезно, если хочется сохранить конструкцию и настраивать её частоты. Работа относится к определённым постановкам спектральных ограничений; она не доказывает, что произвольное точное назначение спектра на любой топологии является выпуклой задачей.

- [Локальный PDF](06-Shafi-Arcak-ElGhaoui-2012.pdf)
- [Открытая авторская копия](https://people.eecs.berkeley.edu/~elghaoui/Pubs/Laplace_IEEE2012.pdf)
- [DOI](https://doi.org/10.1109/TAC.2011.2181795)

## 7. Современный эволюционный подход

**Hendrik Richter, Frank Neumann. Evolutionary Algorithms for Generating Graphs Matching Desired Laplacian Spectra (2026, препринт v1; на странице arXiv указано принятие на GECCO ’26).**

Эволюционный поиск графов, приближающих заданный спектральный дескриптор. Рассматривается также разнообразие других свойств генерируемых графов.

**Важное отличие:** авторы используют нормированный лапласиан I − D^(−1/2) A D^(−1/2) и сглаженную спектральную плотность. Наш прототип использует D − A. Поэтому можно перенести идеи поиска, но спектр и функцию ошибки необходимо адаптировать.

- [Локальный PDF](07-Richter-Neumann-2026.pdf)
- [arXiv](https://arxiv.org/abs/2603.28151)
- [HTML](https://arxiv.org/html/2603.28151v1)

## С чего читать

1. **Ipsen–Mikhailov:** ближе всего к нашей модели колебаний и поиску без весов.
2. **Fallat–Gupta–Lin, теорема 2.5:** короткий путь к точному построению заданных частот с весами.
3. **Devriendt et al., раздел 7:** более богатая конструкция с управлением структурой собственных векторов.
4. **van Dam–Haemers:** почему спектрально одинаковые графы могут быть разными.

Пояснения о применении к музыкальному проекту — наша интерпретация результатов, а не заявленные авторами музыкальные приложения. Открытая доступность файла сама по себе не означает свободную лицензию на дальнейшую публикацию.
