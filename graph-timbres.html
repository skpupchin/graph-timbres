Как строится граф

Для заданных отношений строим полный граф на одну вершину больше, чем задано частот. По теореме 2.5 Fallat–Gupta–Lin положительные жёсткости рёбер дают собственные значения, равные квадратам отношений частот, и одну нулевую моду. Построение выполняется сразу; частоты проверяем по полученным рёбрам. Описание конструкции.

Для варианта «Похожий на текущий граф» ищем другой граф с единичной жёсткостью рёбер. Адаптация метода Ipsen–Mikhailov (2002): частоты √λ сглаживаются лоренцевыми пиками ширины γ = 0.08; сравниваем нормированные плотности по L²-расстоянию. Нижняя положительная частота каждого спектра приведена к 1, поэтому ищем отношения. Интеграл вычисляется численно на конечном интервале. Каждая положительная мода имеет равный вес в плотности.

Случайно меняем связи одной вершины. Улучшение принимается всегда, ухудшение — с вероятностью exp(−Δε/(εθ)), θ = 0.04. Несвязные варианты отклоняются; каждые 1000 изменений начинаем новый случайный поиск, сохраняя лучший результат. Совпадение сглаженных спектров не гарантирует одинаковый тембр при ударе.

Какая модель здесь звучит?

Вершины имеют единичную массу, рёбра задают жёсткости пружин. Нарисованные вручную рёбра имеют жёсткость 1; граф по заданным частотам использует рассчитанные положительные жёсткости. В L = D − A матрица A содержит жёсткости рёбер, D — их суммы у вершин. Лапласиан описывает массы и пружины: ü + Lu = 0. Собственные значения λ дают частоты f = a√λ. Все графы используют один масштаб a; нижние ноты отдельно не выравниваются.

Весь спектр: каждой положительной моде назначена амплитуда 1 и одинаковая начальная фаза. Частота кратности m получает суммарную амплитуду m. Это условное озвучивание спектра.

Отклик: начальное смещение равно нулю, единичный импульс скорости приложен к вершине i, слушаем смещение вершины j. Для ортонормированных собственных векторов амплитуда моды равна vₖ(i)vₖ(j)/(2πfₖ). При кратном собственном значении суммируются вклады всего собственного подпространства; результат не зависит от выбранного базиса.

s(t) = e⁻ᵗ/τ ∑ Aₖ sin(2πfₖt)

Экспонента добавлена как огибающая, а не как точное решение системы с трением. Нулевая мода исключена. Каждый сигнал нормируется по пику перед применением общей громкости, поэтому сравнение абсолютной силы отклика здесь не сохраняется. Частоты выше предела Найквиста не синтезируются. Это озвучивание математической модели, а не расчёт излучения реальных пружин в воздух.
